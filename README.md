# Horta em Casa

Mini projeto em HTML e CSS com um guia introdutório para cultivar alimentos em casa. O conteúdo está organizado em cinco etapas, desde o planejamento até a colheita.

## Páginas

- `html/homepage.html`: apresentação do guia e acesso às demais páginas.
- `html/planejamento.html`: escolha do espaço, iluminação e espécies.
- `html/plantio.html`: preparo dos vasos, substrato e plantio.
- `html/cuidados.html`: rega, nutrição e manutenção das plantas.
- `html/pragas.html`: observação, prevenção e manejo cuidadoso.
- `html/colheita.html`: ponto de colheita e conservação dos alimentos.

## Estrutura

```text
.
├── css/
│   ├── homepage.css
│   ├── planejamento.css
│   ├── plantio.css
│   ├── cuidados.css
│   ├── pragas.css
│   └── colheita.css
└── html/
	├── homepage.html
	├── planejamento.html
	├── plantio.html
	├── cuidados.html
	├── pragas.html
	└── colheita.html
```

O arquivo `css/homepage.css` contém os estilos compartilhados e as regras responsivas. Cada página também carrega seu próprio CSS para personalizar sua identificação visual.

## Como abrir

Abra `html/homepage.html` em um navegador. Use o menu lateral para navegar pelas cinco etapas; cada página também oferece um link para voltar ao início.
